# Architecture Decision Records

ADRs decide architecture, dependency posture, storage, deployment, or important
operational boundaries. Only `Status: accepted` records govern implementation.
Other statuses are `proposed`, `superseded`, and `rejected`.

Copy [template.md](template.md) to a numbered, descriptive filename. Explain the
decision, why it is needed, and its consequences. Superseded records must link
their replacement; keep history visible. Never treat unverified evidence or
pending foundation documents as accepted authority.
