# Automatic session digests and durable support

Status: accepted

## Source

The full user-authorized [automated memory plan](../research/automated-memory-improvement-plan-2026-10-07.md)
governs this amendment. Existing capture, provider, support, human-review and
privacy contracts retain their authority.

## Contract

### Automatic digests

Produce short canonical handovers from current supported claims, decisions and
procedures after five quiet server-receipt minutes or task closure, once relevant
processing/learning/support work settles. Use admitted evidence only; no private
task labels, local paths, hidden reasoning or transcript scraper. A session/task
is provenance, not an account ACL within a shared Brain.

Freeze partitions by Brain, authenticated capture binding/task, host session,
nullable child identity, exact selection and nullable manifest. Scope/child changes
remain distinct; missing manifest remains absent. Add server receipt sequences;
legacy backfill supplies a stable watermark without reconstructing arrival order.
Closure never fences late uploads. Pending, empty, unsupported and budget-deferred
outcomes require no user action and do not trigger repeated paid calls.

Freeze sorted exact eligible contributors plus policy/prompt/schema/verifier and
deterministic page. Deduplicate that root generation; receipt-only changes with
unchanged contributors advance coverage without synthesis. Each page allows at
most twelve contributors/twenty distinct supports, omits whole over-budget inputs,
and records coverage. Admit at most two new generations per coordinator pass. Prioritize uncovered
receipts and rotate bounded scans through otherwise unchanged partitions using
server last-checked time. This prevents old settled sessions from starving later
corrections or policy changes. Record denied source classes separately from whole
input-budget omissions. A failed ancestor does not invalidate a permitted active
retry; once the bounded leaf is terminal, unchanged inputs cannot revive it.
Never summarize another handover. Preserve one claim identity per partition/page
across supported updates, using existing frozen base and support checks. Late
arrivals or changed contributor heads immediately invalidate continuation until
settled coverage catches up; no newest-timestamp association.

Queue through the standing policy writer, device/operation absent. Retain original
contributor attribution separately. Fixed title: `Session continuation`. Recheck
current writer, policy, lease, scope, base and source evidence at admission and
publication. Reuse existing staged handover generation/assessment, budget deferral,
known-completed replacements and bounded local recovery. Unknown completion never
permits blind resend. Empty/withheld outcomes cannot claim an old digest is complete.
Apply current-generation eligibility to every canonical consumer, not only plugin
lookup. Include metadata/stages in RLS, deletion order, privacy closure, cancellation,
logical deadlines and old-backup journal normalization/replay. Scrub controlled
partition metadata while preserving content-free tombstones and unrelated memory.

### Automatic minimal excerpts

Only successful supported new automatic learning publication creates copies; no
broad legacy rewrite. Require current writer authority, `allow_document_content`,
`allow_support_excerpts` and both original/excerpt transmission classes. Retain the
exact cited span, at most 8 KiB, reuse an identical selection, and never truncate a
required span. Missing permits or overlarge spans retain raw support and its eventual
qualification rather than fabricating durability.

Persist original source/version/lines, time, role, capture event/binding, original
class, exact selection and nullable manifest. An assistant reply remains an
assistant statement. Copying supplies the same evidence, never corroboration.
Keep the saved candidate stage immutable. Before publication remap canonical
support IDs/coordinates using a server-created exact equivalence map. Carry its
supported assessment forward only when mapping back reproduces the assessed
content exactly and source/copy bytes, attribution, scope, manifest and times agree.
This changes storage identity, not meaning, and adds no provider call.

The final revision requires the retained excerpt instead of active raw text;
original provenance remains an erasure dependency. Preserve existing real
contributor dependencies; never remove historical raw-dependent edges to fake
durability. Human-owned/reviewed records remain unchanged. Raw expiry preserves
independently retained excerpts; erasing original evidence removes copies and
all dependent memory. Excerpt expiry independently removes dependent memory.

Exclude automatic copies from both automatic source selectors and nested copying.
Gateway resolution requires `support_excerpt` and its persisted original class;
excerpt permission cannot bypass denied raw-session/tool-output transmission.
Register an opaque durable artifact intent before writing optional excerpt bytes,
independently of the publication transaction. Publication atomically replaces the
intent with its canonical source/version identity. Failed writes and rollbacks
remove unreferenced files without another model call; abandoned intents are
reconciled after the worker lease ends, only in the server maintenance context.
Keep content-free removed-intent identities until original/Brain erasure so a
pre-cleanup backup cannot restore forgotten copied bytes. A failed file removal
remains pending while unrelated maintenance proceeds. Original-source and Brain erasure include
pending and removed intent artifacts in the same durable journal/restore barrier. Never sweep
unregistered or neighboring files. All optional copies, intents and equivalence
maps participate in canonical Brain deletion, privacy/replay and restore barriers.

## Acceptance

Prove quiet/closed/abrupt sessions, settlement, unchanged-input zero-call updates,
late refresh, duplicate scheduling, child/scope partitions, bounded omissions and
nullable manifest preservation. Prove supported exact copying without another
charge, original role/scope after raw expiry, original-class denial, no learning
loop, disabled/oversized qualification and protected/historical controls. Exercise
in-flight removal, stale base, source/excerpt expiry, older-backup replay and Brain
deletion with independently supported positive controls.

## Explicit Deferrals

Local acceptance and the versioned synthetic support comparison are recorded in
[the implementation mapping](../mappings/memory-source-support-staging-2026-10-07.md).

change to human authority is authorized by this contract.
