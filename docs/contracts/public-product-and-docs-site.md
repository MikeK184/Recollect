## Contract

- Publish a static product landing page and searchable operator documentation
  on the existing public repository's GitHub Pages site at
  `https://recollecthub.com`. The former project URL
  (`https://mikek184.github.io/Recollect/`) redirects there through GitHub Pages.
  Canonical, sitemap and Open Graph URLs use the custom domain.
- The site builds for the domain root (`/`). `SITE_BASE` remains available for a
  preview under a project path; the build and the static check use the same base.
- Present shared memory, dynamic skills, governed MCP tools, private execution
  and peer coordination as one self-hosted workflow, with the plugin and direct
  MCP as the two ways an agent connects.
- Visual system: the version 2 design system. Colours come only from
  `web/src/design/tokens.css`, which the site theme imports; VitePress variables
  map onto those roles. Light and Ink follow the system setting until a person
  chooses one in the site's theme switch, the choice is remembered, and the
  theme is applied before first paint. Mona Sans sets the interface, JetBrains
  Mono machine text, and Newsreader only the wordmark. Fonts and their OFL
  notices are self-hosted from `web/public/`; the site makes no external font
  request. The original mark sits on its `brand-paper` tile in both themes.
- Motion follows the design system's tokens and its reduced-motion rule. Routes
  fade and rise 4px; search rises like the command palette. Explanatory
  diagrams are complete at rest, animate an illustrated sequence only while at
  least a third of the diagram is on screen and the tab is visible, show one
  packet per illustrated event, offer a visible pause control and step chips,
  and under reduced motion show each step's end state without packets.
  Diagrams and the README illustrations use labelled example data.
- The website is documentation, not an application installation. It contains no
  account login, Brain records, private runtime data, model calls or credentials.
- Canonical operator Markdown remains in `docs/runbooks/` and the plugin README.
  An explicit allowlist generates the website's documentation from those sources;
  links to unpublished repository records go to their public GitHub sources.
- A separately locked VitePress build in `site/` produces only static artifacts.
  Generated content, dependencies, caches and build outputs remain ignored.
- GitHub Actions builds/checks the site and deploys the artifact from `main`.
  Pull-request builds may validate but cannot deploy. Deployment permissions are
  limited to the deployment job, with no additional repository secrets.
- Support deep links, syntax highlighting in both themes, local documentation
  search, accessible navigation, visible focus and phone-width layouts without
  horizontal page scroll.
- The README's animated illustrations are SVG files generated by
  `scripts/render-readme-art.mjs` from the same tokens, in Light and Ink pairs
  selected by GitHub's theme. They use SMIL and CSS only, hide moving packets
  under reduced motion and read correctly with motion off.
- Existing local acceptance/production limits remain explicit. Product
  illustrations are examples, not current installation screenshots.

## Acceptance

Build from locked dependencies; verify generated routes, internal links, anchors
and assets with the site check; inspect the product page and a guide in Light and
Ink at desktop and phone widths, including diagram playback, pause and reduced
motion; exercise local search and code copying; run `./scripts/validate.sh`. A
successful GitHub Pages deployment and HTTPS requests that load the product page,
its stylesheet and a guide on `recollecthub.com` establish publication. Local
builds alone do not establish a live site.

## Explicit Deferrals

Analytics, hosted accounts, application runtime hosting and product performance
claims remain separate.
