These documents contain the revised accepted product direction of 2026-09-13.
The user selected Rust for Recollect's own backend and local companion and approved
the researched stack and product defaults. This replaces the mandatory Cognee/
Python extension baseline. Dated research and prior closeouts remain historical
evidence; the [decision mapping](../mappings/atlas-foundation-decisions-2026-09-13.md)
records research coverage, selected defaults, alternatives and verification gaps.

Use one governed memory model with complementary forms and retrieval methods.
All seven Atlas capabilities are intended obligations, with explicit behavior
and proof boundaries; none is claimed as delivered. Cognee and the other
reference systems inform design and optional component evaluation.

The MCP coordinator and Vault integration remain in the first usable product,
alongside knowledge collections, repository memories, both graph forms and queued
analytics. Brains enforce knowledge access; areas/environments organize overlapping
views, and profile grants separately authorize execution.

Support local or shared installation, local accounts with optional OIDC,
policy-based automatic learning, labeled disputed material in investigations,
strict recall, per-Brain provider/content rules, 30-day sanitized session retention
and separate Withdraw/Erase actions. Exact schemas, dependency pins, policy rules,
provider/host compatibility and deployment service levels still need contracts.

The user's requested sequence is foundations first, then product epics derived
from them, then the applicable detailed decisions and execution packs. This
foundation rewrite created no product epics or implementation packs. The subsequent
user-authorized [epic derivation](../roadmap/epics/index.md) now provides seven
planned product epics. The current user-authorized implementation has started with platform-bootstrap;
follow the epic/execution indexes for delivery state.
Existing developer tooling and reference checkouts remain available.
