## Local implementation

- Migrations 036–038 add bounded immutable typed extraction/handover stages,
  independently indexed whole-assertion verdicts and per-revision/policy/verifier
  assessments. New unsupported additions allocate no usable memory; unsupported
  corrections/retirements and handover refreshes preserve the old head.
- The shared canonical support predicate gates recall before ranking/limits,
  semantic/graph inputs, answering, synthesis, conflict/reuse and cached context.
  Direct and legacy unreviewed contributions receive bounded automatic audits.
  Explicit authenticated human decisions retain their authority; required
  contributors cannot acquire support through a reviewed parent.
- `source-support-3` requires an evidence quotation found in the action's exact
  cited spans or explicitly admitted canonical fact/contributor body. Candidate
  text, surrounding framing windows and metadata cannot supply that quotation.
  Missing/misattributed anchors become terminal insufficient evidence. The model
  still evaluates meaning; an exact quotation is not a truth guarantee.
- Migration 039 partitions automatic session digests by authenticated
  binding/task/session/child, exact selection and nullable manifest. Five quiet
  receipt minutes or task closure schedule settled work. Late inputs and changed
  contributors immediately invalidate old delivery. Bounded fair scans progress
  beyond the first 100 partitions; unchanged eligible inputs refresh coverage
  without new model calls. Digests use canonical handover synthesis/support,
  not recursive summaries or a second memory store.
- Permitted exact supporting excerpts preserve original class, speaker, scope,
  manifest and line/time lineage. They survive ordinary raw expiry under their
  own retention and never become independent corroboration or another learning
  loop. Original erasure removes them. A durable opaque artifact-intent ledger
  precedes file writes; lease checks prevent premature cleanup. Removed intent
  tombstones preserve old-backup erasure mapping. One bad file does not stop
  unrelated maintenance.
- Migration 040 validates immutable closed-task continuation predecessors with
  the same Brain, actor, device and exact selection. Deterministic supported
  decisions/conventions/constraints share normal recall's budget: at most three
  brief records/1536 bytes, one unambiguous continuation page, six total plugin
  records and 8192 bytes including escaped JSON/framing. The existing eight-second
  rich/fallback deadline remains. Brief assembly adds no model call and never
  guesses the newest session, repository or environment.
- Cross-session discovery is bounded exact-family matching under current scope,
  manifest, validity and human-rule gates. A sole match supplies a frozen
  replacement/reuse hypothesis to the assessor. Multiple matches or insufficient
  budget record omitted coverage. Unsupported relationships preserve existing
  knowledge; faithful same-value reuse allocates no new revision or renewed TTL.

## Recovery and privacy

Budget/slot denial before transmission defers the same work key. Known completed
assessment failures permit at most two linked separately charged replacements,
inheriting extraction/draft, frozen targets and original lifetime. Committed
verdicts survive native publication/database recovery without another model call.
A completed or uncertain response lost before durable typed commit is not blindly
resent. Semantic insufficiency is terminal for unchanged inputs.

Stages, assessments, excerpt aliases/intents, digest coverage and linked requests
participate in logical deadlines, cancellation, Brain deletion and transitive
privacy-journal replay. Actual older-database/artifact fixtures test restore
barriers and erasure replay. Final excerpt expiry scrubs its affected session
partition while an independently supported control remains eligible.

## Actual-model support comparison

The frozen corpus contains 50 synthetic cases: 24 calibration and 26 held-out.
Gold labels/category/critical flags are excluded from model inputs. Each native
case creates ordinary canonical evidence and an unchecked contribution, runs the
native automatic support worker through the installed approved gateway, then
reads actual canonical investigation eligibility and recall delivery. The harness
records request/response model identity, charge and latency; it does not reset a
verdict or repeat a case until favorable. Earlier runs remain separately retained.

v1/v2 incorrectly accepted a port assertion when its syntactically valid citation
covered only an indentation statement; the port appeared in an uncited neighboring
line. The v3 exact quotation guard withholds it. All v3 cases completed; all 28
negative cases were withheld and 21/22 positive cases remained usable. The missed
calibration positive is `cal-explicit-retirement`. Disposition agreement is reported
separately: contradicted versus insufficient differences are not false usability.

The final v3 held-out comparison meets the predeclared zero-critical-false-usability,
at-least-80%-positive-usability and complete-assessment thresholds. All retained
measured runs total **124 distinct calls and 148,288 charged tokens**, below the
250,000-token isolated allowance; v3 alone uses 50 calls/63,222 tokens. No customer
content was used. [Checked-in synthetic observations, scores and receipt hashes](../research/automatic-memory-support-results-2026-10-07.json)
preserve the failures and final comparison; private native receipts remain in the
owned local evaluation cache.

This is a repeated fixed-corpus comparison after calibration-driven changes,
not an unseen-population accuracy estimate, independent truth check or superiority
claim. The assertion adapter does not measure every typed producer-action mutation;
those action boundaries have separate controlled native fixtures. Matching quotes
remain semantically fallible; very short scalar-only anchors may be withheld.

## Validation and operational limits

Focused native proofs cover staged publication, all canonical consumers,
current/legacy/direct/human controls, bounded retries and saved verdicts, budget
and near-input-limit behavior, mixed procedures/retirements, source/manifest/epoch
invalidation, in-flight erasure and older restore replay. Automatic-session tests
exercise settled/closed/late/restarted sessions, exact excerpt lineage, original
class denial, final support expiry, rollback intent recovery and scanner fairness.
Native retrieval proves no-charge brief/continuation, immediate late-input
invalidation, spoof rejection and actual ended-task predecessor resume. Agent
unit tests count escaped JSON and OpenCode host metadata within the hook cap.
Final focused checks passed 29 native support scenarios, six automatic-session/
digest scenarios, three retention/deadline scenarios, one additional learning
recovery scenario, all 20 server and 34 agent library tests. OpenAPI generation
validated 184 unique operations; workspace Clippy with warnings denied, web design/
type checking, governance lint/all 32 checks, the 50-case corpus validator, all
10 scorer tests, CodeGraph sync and `git diff --check` passed. Native fixture
verdicts establish enforcement/recovery, not semantic reasoning. Owned failed
fixture databases/state were removed after the successful fixes; evaluation
observations and private receipts were preserved.

The recall request schema keeps the new project-brief and continuation options
optional. UI callers explicitly retain the server defaults (`false` and `null`),
matching the TypeScript generator's required-default convention.

No new UI, release, commit, push or local runtime deployment is claimed. A later
operator upgrade must apply compatible migrations and update the plugin binary.
Already delivered host context cannot be retracted by later correction/erasure.
Missing capture is an honest gap. Public memory benchmarks and their independently
blocked protocols/budgets are outside this synthetic support evaluation.
