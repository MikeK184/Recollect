# Desktop design

The accepted [design system](../../foundation/design-system.md) specifies the light cream/ink/sage
palette, typography, motion, layout and management presentation. The
[desktop contract](../../contracts/desktop-experience.md) and
[Knowledge surface contract](../../contracts/desktop-knowledge-surface.md)
govern behavior. Use the [desktop runbook](../../runbooks/desktop-experience.md)
for current navigation and [current roadmap](../epics/index.md) for open work.

The earlier twelve-screen gallery, image prompts and pre-implementation audits
were removed after their selected behavior moved into the contracts and running
UI. They are historical concepts, not current screens; the
[fixed Git snapshot](https://github.com/MikeK184/Recollect/tree/f2673d71c4b63b536d41b3143eb39c207955b201/docs/roadmap/desktop-experience)
retains them. Current product identity assets remain in `web/public/brand/`;
current README illustrations remain in `docs/assets/`.
