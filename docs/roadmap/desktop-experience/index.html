      Implementation boundary

      The recommendation

      Keep React and TypeScript. Build shared light-theme tokens and components using the Atlas palette and Newsreader, Manrope and DM Mono typography.

      Ask becomes the main entry point. Sources, memory and graphs make its evidence inspectable. Agents do routine work; people configure permissions and intervene when useful.

      Fonts inside generated images are visual approximations. Exact implementation tokens, accessible states and source links are in the written design system.

      Deliver in bounded steps

      1. Agree the navigation and behavior contracts.
      2. Build the tokens, shared shell and nested routes.
      3. Move existing capabilities into focused pages.
      4. Add governed Ask answers and temporary follow-ups.
      5. Validate human and agent journeys, then cut over.
