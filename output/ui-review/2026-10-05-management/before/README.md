## Cross-page gaps to check after implementation

- Global navigation must separate Brains/My agents/Connectors from Brain links.
- Preserve cream/ink/sage and the existing logo/icon family; concept-generated marks are not new brand assets.
- Heading, supporting copy, primary action and control sizes must be consistent.
- Replace random advanced/history disclosures with named destinations and focused panels.
- At 1440 × 900, prevent inspector and authentication text from squeezing inputs or requiring sideways scroll. At 1920 × 1080, use intentional widths rather than stretched empty cards.
- Do not label a saved definition, credential or connection live. Past observed use and absent tests must stay explicit.
- Opening and cancelling edit flows must leave persisted state unchanged; reviewer will not invoke tests, external calls or save operations.
- Empty/no-match, loading, permission denial and parse errors need specific readable states, with recovery where the product supports it. Parent owns isolated fixture proof.

No product changes were made by the independent reviewer. Offline tests and external
connectivity are outside this baseline; visible configured status is not successful
MCP connectivity proof.
