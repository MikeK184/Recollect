# Recollect identity

The original mark expresses **gathering again**: three interrupted paths return
to a smaller inner loop and a remembered point. Its open spaces suggest that
memory is reconstructed from fragments rather than a perfectly closed archive.

- `recollect-symbol.svg`: full-color mark, also the browser favicon.
- `recollect-symbol-mono.svg`: one-color version for print and restricted palettes.
- `recollect-logo.svg`: portable mark and outlined Newsreader wordmark; no font
  installation or external resource is required to display this file.

Use `Brand` in the application so live text uses the same self-hosted typography
as the interface. Minimum symbol size: 24px; normal navigation size: 36px.
Preserve its square aspect ratio. Use a light paper/white background with clear
space of at least one eighth of the symbol width.

The wordmark is outlined from Newsreader at weight 500 / optical size 40.
Font source/version/checksums are in `../fonts/manifest.json`; its SIL OFL notice
is in `../licenses/newsreader-OFL.txt`. Original mark authored for Recollect
on 2026-09-26. Palette and typography follow the accepted desktop design system.
